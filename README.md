# Vista previa estática — Shanti Lanka Ashram

Copia estática de solo lectura del sitio, publicada con GitHub Pages para
poder mostrarla con un enlace.

No es el sitio real: los formularios no envían datos (avisan con un mensaje)
y el panel de administración no existe aquí.

El código real del sitio (PHP + SQLite) vive en la rama `main`.
